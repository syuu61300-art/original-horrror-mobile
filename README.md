# 沈灯（ちんとう）― 灯籠ヶ沢の祈り

ダム湖の底から現れた廃村「灯籠ヶ沢」を、行方不明の妹・凪を探して歩く一人称ホラー。
ブラウザだけで動きます（three.js r186 + cannon-es、WebGL2）。
**テクスチャ・3D モデル・効果音・音楽はすべてプログラムで生成**しており、外部の画像や音声ファイルは一切使っていません。

- 全五章／三つの結末（A 帰還・B 身代わり・C 消灯）
- 武器なし。手にできるのは懐中電灯・古い手持ち提灯・お札フィルムのビデオカメラだけ
- 怪異ごとに異なるルール（見ている間は動かない・灯りを嫌う・音だけを頼りに這う・鈴の音とともに追う）

## 起動方法

| 目的 | 開くもの | 備考 |
|---|---|---|
| **遊ぶ** | `index.html` をダブルクリック | 単体版。すべてのコードを 1 ファイルに内蔵。サーバー不要 |
| 改造・開発 | `dev.html` | `src/` の ES モジュールを直接読み込む。**ローカルサーバー経由**で開く（下記） |

推奨ブラウザ：最新の **Chrome / Edge**（主にこの 2 つで確認しています。WebGL2 に対応した Firefox / Safari でも動く想定です）。WebGL2 が必須です。
**ヘッドホン推奨**（立体音響で怪異の位置が分かります）。

- インターネット接続は日本語フォント（Google Fonts）の取得にだけ使います。オフラインでも代替フォントで遊べます。
- 初回起動時、タイトル画面の描画速度を数秒測り、重ければ自動で画質を下げます（設定でいつでも変更可）。
- 進行は章のチェックポイントごとにブラウザ（localStorage）へ自動保存されます。「つづきから」で再開できます。

### 開発版（dev.html）の開き方

```bash
cd chinto
python3 -m http.server 8080        # または: npx serve .
# ブラウザで http://localhost:8080/dev.html
```

three.js / cannon-es は import map で CDN（jsDelivr、バージョン固定）から読み込みます。
`src/` を編集してブラウザを再読み込みすれば、ビルドなしで反映されます。

### 単体版を作り直す

```bash
npm install
npm run build        # index.html（圧縮）と dist/artifact.html を生成
npm run build:dev    # 圧縮しない版（デバッグ用）
```

## 操作方法

| 操作 | キーボード・マウス | ゲームパッド |
|---|---|---|
| 移動 | W A S D | 左スティック |
| 視点 | マウス（矢印キーでも可） | 右スティック |
| 走る（スタミナ消費） | Shift | L3 / RB |
| しゃがむ | Ctrl（押している間）／ C（切り替え） | Ⓑ |
| 調べる・拾う・隠れる・出る | E（長押しが必要なものもある） | Ⓐ |
| 懐中電灯 オン／オフ | F | Ⓧ |
| 提灯を掲げる／しまう | Q | LB |
| カメラを構える（ナイトビジョン） | 右クリック（押している間）／ R（切り替え） | LT |
| 撮影（お札フィルムで怪異を一瞬止める） | 構えて 左クリック／ Space | RT |
| ズーム（カメラ） | マウスホイール | ― |
| **導き（次にすることと方向を表示）** | **H** | 十字キー↑ |
| 手帳（日記・文書・地図） | Tab ／ J | Ⓨ ／ Back |
| 一時停止 | Esc ／ P | Start |
| カットシーンを飛ばす | E 長押し | Ⓐ 長押し |
| メニュー操作 | マウス・矢印キー・Enter／Esc | 十字キー・Ⓐ／Ⓑ |

- 画面をクリックするとマウスが固定されます（Esc で解除＝一時停止）。
- 画面の表示は最小限です。電池の残量はライトのちらつきで、怪異の接近は心音と画面端の脈動で分かります。

### スマートフォン・タブレット

タッチ操作に対応しています（横向き推奨。縦向きでは回転を促す表示が出ます）。
- **画面左半分**：触れた所に現れるスティックで移動（端まで倒すと早く歩く）
- **画面右半分**：なぞって視点移動
- **右下のボタン**：調べる（長押しでカットシーンを飛ばす）／ライト／提灯／カメラ（構えると「撮影」ボタンが出る）／しゃがむ／走る（タップで切替）／振り向く
- **右上**：導き／手帳／一時停止
- スマホでは初回、画質「低」から始まります。重い場合は設定で「解像度」を下げてください。

## 遊び方のヒント（ネタバレ少なめ）

- **灯りは盾であり、目印でもある。** 懐中電灯は遠くからでも見つかりやすくなります。電池は有限です。
- **走ると提灯の火は消える。** 消えた提灯は、灯っている灯籠の前で E を押すと火を移せます。
- **しゃがむと足音が小さくなる。** 目のない怪異には、これが一番効きます。
- **隠れ場所（甕・納戸・井戸の縁）は万能ではない。** 長く隠れると灯が弱まり、同じ場所ばかり使うと覚えられます。
- **カメラのナイトビジョンでしか見えないものがある。** フィルムは数が限られています。
- **迷ったら「導き」（H キー／導きボタン）。** 次にすることが表示され、向かう場所に灯の印が出ます（画面外なら端に矢印）。しばらく進展がない時は自動でも示されます。一時停止画面にも目的が出ます。
- **手帳の「手掛かり」タブ**に、今わかっていることがまとまります。行き詰まったら開いてください。
- 死んだ時に表示される短い詩は、その怪異への対処のヒントです。
- 結末 C には、第二〜四章に一枚ずつ隠された「手帳の切れ端」が三枚とも必要です。

## 画質設定

設定 → 画面 →「グラフィック品質」で 低／中／高／最高 を選べます。
解像度（50〜100%）・フレームレート上限（無制限／60／30）・明るさ・視野角・各種エフェクトも個別に切り替えられます。

| プリセット | 影 | ボリュメトリック光 | SSAO | 水面反射 | 被写界深度・ブラー | 光源数 |
|---|---|---|---|---|---|---|
| 低 | 512 | なし | なし | なし | なし | 3 |
| 中 | 1024 | 10 段 | あり | 30% | なし | 5 |
| 高（既定） | 2048 | 16 段 | あり | 50% | あり | 8 |
| 最高 | 2048 | 26 段 | あり | 75% | あり | 10 |

重いと感じたら、まず「解像度」を 75% に、それでも重ければ品質を一段下げてください。
ノート PC では電源に接続し、ブラウザの「ハードウェア アクセラレーション」を有効にしてください。

## ファイル構成（概要）

```
index.html            単体版（遊ぶ用・ダブルクリックで起動）
dev.html              開発版（src/ を直接読み込む・要ローカルサーバー）
src/
  main.js             エントリポイント
  core/               エンジン・入力・物理・セーブ・経路探索・共通道具
  gfx/                テクスチャ焼成・マテリアル・霧・光源・水面・粒子・後処理・建物・怪異モデル
  audio/              WebAudio ミキサー（3D 定位・遮蔽・残響）／手続き生成の効果音と和楽器／環境音
  ai/                 敵 AI（感知・状態遷移・隠れ場所の学習）と 4 種の怪異
  game/               進行管理・プレイヤー・装備・正気度・調べる操作・カットシーン・全テキスト
  chapters/           タイトル背景と第一〜五章のレベル
  ui/                 画面（DOM）：タイトル・HUD・手帳・設定・ゲームオーバー・エンディングほか
tools/                ビルドスクリプトと自動テスト（ヘッドレスブラウザ）
docs/設計書.md         全体設計・レベルデザイン・調整パラメータ・拡張案・素材差し替えガイド
```

詳しい設計・各章の配置と謎の解法・調整できる数値の一覧は **[docs/設計書.md](docs/設計書.md)** にあります（解法を含むので、クリア前に読む場合はご注意ください）。

## 動作確認について

`tools/run.py` と `tools/tests/` に、ヘッドレス Chromium でタイトル→各章→結末までを自動で操作する検証シナリオがあります。

```bash
pip install playwright && python3 -m playwright install chromium
CHINTO_Q=low python3 tools/run.py out/t1 tools/tests/t1_ch1_ui.js 800 450
```

（ソフトウェア描画のため、実機よりずっと遅く動きます。シェーダの準備に数分かかることがあります。）
